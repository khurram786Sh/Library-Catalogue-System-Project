# Library System Project

## Overview:
The Library System Project is a software application designed to help users manage a library catalog efficiently. It provides features for adding, searching, deleting, and sorting books by title or author. This user manual will guide you through the installation and usage of the software.

## Features:
- Add books to the library catalog
- Search for books based on keywords
- Delete books from the catalog
- Sort books by title or author
- View a list of all books in the catalog

## System Requirements:
- Operating System: Windows, macOS, or Linux
- Python 3.x
- Tkinter library (usually included with Python installation)

## Installation:

1. Ensure that Python 3.x is installed on your system.
2. Open a command prompt or terminal.
3. Install the Tkinter library if it's not already installed (it typically comes with Python).

## Running the Application:

1. Open a command prompt or terminal.
2. Navigate to the directory where the `library_system.py` file is located.
3. Run the following command to start the application:
   ```bash
   python library_system.py
